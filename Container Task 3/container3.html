This is JPG

A JPG file is a popular image format used for storing and sharing digital pictures. It uses compression to reduce file size while keeping good image quality, making it ideal for websites, emails, and photography. JPG files can display millions of colors and are supported by most devices and software. However, repeated saving can lower image quality because some data is permanently removed during compression. Despite this, JPG remains one of the most common image formats worldwide.
